# University Transport Management System (C++)

## Project Overview
The University Transport Management System is a console-based application developed in C++ using Object-Oriented Programming (OOP) concepts. It is designed to manage university transportation operations efficiently, including vehicles, routes, students, drivers, transport applications, and fee records.

## Key Features
- **User Management:** Manage student, staff, and driver records.
- **Vehicle Management:** Add, remove, and view buses and vans.
- **Route Management:** Create routes, assign vehicles, and calculate monthly transport fees.
- **Transport Applications:** Apply for transport and approve or reject applications.
- **Driver Management:** Register drivers and assign vehicles.
- **Fee Management:** Maintain transport fee records and calculate late fees.
- **Reports:** Generate route-wise reports and revenue summaries.
- **File Handling:** Save and load data using text files.
- **Login & Registration:** Provide user registration and login functionality.
- **Input Validation:** Handle invalid numeric inputs using templates.

## OOP Concepts Used
- Classes and Objects
- Inheritance
- Encapsulation

- Polymorphism
- Constructors and Destructors
- Copy Constructors and Assignment Operators
- Operator Overloading
- Function Templates
- Dynamic Memory Allocation
